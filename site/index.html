Where the difference came from

By year

Brinson-Fachler effects, linked across days with Carino's method so they add up exactly to the cumulative active return. Allocation: over- or underweighting segments that beat or lagged the benchmark. Selection: holdings beating or lagging their own segment's benchmark.

Model checks

Each model is tested against something published independently. The live checks below use this snapshot's data; the rest run on every commit in the test suite.
